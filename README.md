# Blinkit SQL Data Analysis Project 🛒

## 📌 Project Overview

This project is a SQL-based data analysis project inspired by Blinkit's quick-commerce business model.

The main objective is to practice SQL queries and analyze customer information, product details, orders, categories, and sales data using MySQL.

This project uses fictional dummy data created for learning and educational purposes. It is not official Blinkit company data.

## 🎯 Project Objectives

- Understand relational database concepts.
- Create and manage multiple SQL tables.
- Practice SQL JOIN operations.
- Analyze customer orders and product sales.
- Calculate product-wise and category-wise revenue.
- Solve real-world business problems using SQL.

## 🚀 How to Run This Project

1. Install MySQL Server and MySQL Workbench.
2. Clone or download this repository.
3. Open MySQL Workbench.
4. Run `01_Create_Database.sql`.
5. Run `02_Insert_Dummy_Data.sql`.
6. Execute the remaining SQL query files.
7. Explore the query results and practice the questions.
